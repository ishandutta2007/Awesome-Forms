## 🌟 Overview

A curated list of leading online form builders, survey platforms, conversational form engines, quiz creators, and form handling SDKs for data collection, workflow automation, and customer experience management. 📊

**Primary focus:** Open-source form software & privacy-first self-hosted tools 🔓, complemented by top commercial/hosted SaaS solutions.

## 🛠️ Specialized Libraries & Related Tools

| Category | Recommended Solutions | Primary Focus |
|----------|-----------------------|---------------|
| **Form Libraries for Developers** 💻 | React Hook Form, Formik, SurveyJS, JSON Forms, Schema-Form | Custom / embedded frontend forms |
| **Static Form Backends** 🔌 | Formspree, Basin, Getform, Netlify Forms, Formcarry | Backend submission endpoints for HTML forms |
| **Survey / Quiz Engines** 🎯 | LimeSurvey, Formbricks, SurveyJS Engine | Academic, employee & research assessments |
| **PDF & Document Generation** 📄 | PDFKit, Puppeteer, react-pdf, DocRaptor | Post-submission PDF document creation |
| **Workflow Engines** ⚡ | n8n, Temporal, Activepieces, Windmill | Form submission → multi-step process automation |
| **Analytics & Dashboards** 📊 | Metabase, Apache Superset, Streamlit | Response data visualization & reporting |

## 🚀 Quick Start Recommendations

| Goal | Recommended Starting Point 📌 |
|------|-------------------------------|
| Best overall open-source survey platform | **Formbricks** 🧱 |
| Conversational one-question-at-a-time forms | **Typebot** 🤖 or **HeyForm** 💬 |
| Clean general-purpose open form builder | **OpnForm** 🎨 |
| Mature, research-grade surveys | **LimeSurvey** 📈 |
| Developer / embeddable JSON forms | **SurveyJS** 📊 or **Form.io** 🛠️ |
| React frontend form state management | **React Hook Form** ⚛️ |
| Beautiful conversational hosted forms | **Typeform** 💬 |
| Feature-rich templates + payments | **Jotform** 🧩 |
| Unlimited free simple forms | **Tally** ✍️ or **Google Forms** 📝 |
| Modern forms with strong logic on a budget | **Fillout** ⚡ or **Cognito Forms** ⚙️ |
| Enterprise forms + documents + workflows | **Formstack** 📄 |
| Design + payments + product-style forms | **Paperform** 🎨 |
| Microsoft 365 integrated forms | **Microsoft Forms** 📑 |
| Zoho ecosystem forms | **Zoho Forms** 💼 |
